# Core Insta Hub

인스타그램 계정 여러 개를 **계정별 로그인 상태 그대로** 한 창에서 전환하고, 동시에 나란히 볼 수 있는 Windows 데스크톱 앱입니다.

**[설치 파일 다운로드 (Windows)](https://github.com/cohetelab/insta-hub-releases/releases/latest)**

## 이런 분께

- 인스타 계정을 여러 개 운영하는데, 계정을 바꿀 때마다 로그아웃·로그인하기 번거로운 분
- 여러 계정의 화면을 한 번에 훑어보고 싶은 분 (최대 10개 동시 보기)

## 어떻게 동작하나요

- 계정마다 쿠키와 저장소가 완전히 분리된 별도 브라우저 세션을 씁니다. 그래서 한 번 로그인하면 앱을 껐다 켜도 로그인이 유지됩니다.
- 비밀번호는 앱이 저장하지 않습니다. 인스타그램 공식 로그인 화면에서 직접 입력하고, 앱에는 로그인 세션만 남습니다.
- 로그인 정보는 이 PC에만 저장됩니다. 서버로 보내지 않습니다.

## 설치

1. 위 링크의 Releases 페이지에서 `CoreInstaHub-Setup-x.x.x.exe`를 받아 실행합니다.
2. Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요. 코드 서명이 없는 앱이라 나오는 경고입니다.
3. 설치가 끝나면 앱이 바로 실행됩니다.

## 사용 방법

| 동작 | 방법 |
| --- | --- |
| 계정 전환 | 왼쪽 바에서 계정 버튼 클릭 |
| 계정 추가 | `+` 버튼 |
| 이름 변경 | 계정 버튼 더블클릭 → 입력 후 Enter |
| 계정 삭제 | 계정 버튼 우클릭 (로그인 정보도 함께 삭제됨) |
| 동시 보기 | 왼쪽 바 아래 `1 · 2 · 4 · 6 · 9 · 10` 버튼 |
| 모바일 화면 | 맨 아래 `🖥 PC` ↔ `📱 모바일` 버튼 |

처음에는 계정 2개가 만들어져 있습니다. 계정마다 한 번씩 직접 로그인하세요.

- **동시 보기:** 숫자는 한 화면에 보이는 계정 수입니다. 계정이 그보다 많으면 순서대로 묶어서 보여 주고, 다른 묶음의 계정 버튼을 누르면 그 묶음으로 넘어갑니다.
- **모바일 화면:** 모든 계정에 한꺼번에 적용되며 설정은 저장됩니다.

## 알아두세요

- 같은 PC·같은 IP에서 계정 여러 개를 쓰면 인스타그램이 보안 확인을 요구할 수 있습니다.
- 동시에 많이 열수록 메모리를 많이 씁니다. PC 사양이 낮으면 6분할 이하를 권합니다.
- 새 PC에 설치하면 계정마다 다시 로그인해야 합니다.
- 인스타그램 화면 구성은 인스타그램이 바꿀 수 있습니다. 저장 버튼 위치 등은 화면마다 다릅니다.
- 공식 인스타그램 앱이 아닙니다. 이용 중 발생하는 계정 제한 등은 인스타그램 정책을 따릅니다.
